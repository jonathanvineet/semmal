# Simulation model credits

The `house` world (`ros2_ws/src/semmal_gazebo/config/worlds/house.yaml`) uses these Gazebo Fuel models,
unmodified, placed by `generate_world.py`. Each is licensed under Creative Commons Attribution 4.0
International by its author. They are not committed to this repository. `scripts/robot/fetch_models.sh`
downloads the pinned versions into the local Fuel cache (`~/.gz/fuel`).
