0G · Physical AI + Private Computer · 15 seconds

A robot that cannot pass a checkpoint without 0G.

At every stop it pays an AI agent in 0G, which asks a private TEE model on 0G Private Computer what it sees. The answer and its request ID go into a signed episode on 0G Storage. If 0G is down it stops safely. It never fakes a decision.

0G is the brain, not the spinal cord

The decision loop, at every checkpoint

1 · DriveROS 2 + Gazebo; navigation and safety stay on the robot
→
2 · Lookone camera frame, never stored
→
3 · Hire + payrobot pays the agent owner in 0G; the transfer is checked on chain before 0G is called
→
4 · 0G PC0gm-1.0-35b-a3b, private mode, TEE providers only
→
5 · Checkexact JSON, allowed action, confidence ≥ 0.6
→
6 · Actclear the toys, report, hold or go home: bounded actions only

Model output is advisory. It picks one of five actions; it never touches motors, money or keys.

Native 0G money, on 0G Galileo

The robot has its own wallet and its own budget

Customer → robotpays the robot's signed quote after confirming arrival (memo semmal:quote:<id>)
→
Robot → agent ownerone transfer per agent job (semmal:job:<id>), within the paid budget, never twice
→
Agent → 0G PCits price covers its own capped 0G inference
→
Robot → owner / customerthe margin if done; the unspent rest refunded if not

Allowlisted recipients, per-payment and daily caps, idempotent. The only key is the robot's device key on the robot PC.

Safe stop: no fake decisions

If 0G can't answer, the robot doesn't guess

holdno answer, late, invalid

The robot holds position and retries once with the same paid job.

SAFE_STOPstill no valid answer

It stops safely and records why. Nothing is invented. Tested: "0G fails twice → SAFE_STOP, nothing invented".

localmotor overcurrent

The safety supervisor stops the robot with no network and no AI; the incident is signed and queued until it reaches Storage and Arkiv.
